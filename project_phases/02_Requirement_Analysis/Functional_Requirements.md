# Functional Requirements

## FR01 – User Registration

The system shall allow a new user to create an account.

## FR02 – User Login

The system shall allow registered users to log in securely.

## FR03 – Home Planning

The system shall allow users to enter:

- Room type
- Budget
- Preferred style
- Additional preferences

The system shall generate home planning recommendations.

## FR04 – Party Planning

The system shall allow users to enter:

- Occasion
- Budget
- Number of guests
- Venue type
- Preferences

The system shall generate a party budget plan.

## FR05 – Jewelry Recommendation

The system shall allow users to enter:

- Occasion
- Outfit color
- Jewelry budget
- Jewelry type
- Additional preferences

The system shall generate jewelry suggestions.

## FR06 – Image Upload

The jewelry module shall allow users to upload an outfit image.

## FR07 – Recommendation History

The system shall save generated recommendations for logged-in users.

## FR08 – Dashboard

The system shall provide users with a dashboard containing
available planning modules and recent recommendations.
