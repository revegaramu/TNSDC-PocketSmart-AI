# Non-Functional Requirements

## Performance

The system should return recommendations within a reasonable time.

## Security

Passwords must not be stored as plain text.

## Usability

The interface should be simple and easy to navigate.

## Reliability

The application should continue functioning using the local
recommendation engine when the external AI service is unavailable.

## Maintainability

The application should use a modular architecture.

## Scalability

The application architecture should allow additional recommendation
modules to be added in the future.

## Compatibility

The application should work on modern web browsers.
