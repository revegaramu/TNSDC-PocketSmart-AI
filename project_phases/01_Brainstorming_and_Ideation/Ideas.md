# Brainstorming Ideas

During brainstorming, several possible solutions were considered.

## Initial Ideas

1. Budget calculator
2. Shopping recommendation system
3. Home decoration planner
4. Party budget planner
5. Jewelry recommendation system
6. AI-based personal planning assistant

## Selected Idea

The selected idea was to combine multiple budget-based recommendation
features into one application.

The final project was named:

# PocketSmart AI

## Core Modules

- User Authentication
- Home Planner
- Party Planner
- Jewelry Assistant
- Recommendation Engine
- Recommendation History
